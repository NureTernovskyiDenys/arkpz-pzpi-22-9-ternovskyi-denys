4 РОЗРОБКА IoT КЛІЄНТА
(БІЗНЕС-ЛОГІКИ ТА ФУНКЦІЙ НАЛАШТУВАННЯ)
Мета:
Розробити програмне забезпечення для IoT або SmartDevice пристрою, створеного на базі будь-якої поширеної на сьогодні платформи, придатної для реалізації вбудованих систем (Embedded System).
Хід роботи:
Основні компоненти проєкту TaskLamp
1.	ESP32 DevKit V1
o	Основний мікроконтролер, який відповідає за управління компонентами пристрою, збір даних, синхронізацію часу, обробку завдань і комунікацію з сервером через WiFi.
2.	OLED-дисплей (128x64, SSD1306)
o	Відображає поточний час або список завдань. У разі відсутності завдань виводить повідомлення "0 tasks found".
o	Використовується для швидкого перегляду стану системи.
3.	LED кільце (WS2812B)
o	RGB-кільце з 16 світлодіодами для індикації.
o	Світло змінює кольори та яскравість залежно від налаштувань і стану пристрою.
4.	Потенціометри
o	Яскравість (BRIGHTNESS_PIN): Регулює яскравість LED кільця (0-255).
o	Колір (COLOR_PIN): Встановлює колір LED кільця, базуючись на значеннях аналогового входу.
5.	RTC-модуль (DS1307)
o	Реальний час синхронізується для відображення поточного часу на екрані.
6.	WiFi-з’єднання
o	Використовується для обміну даними із сервером: 
	Отримання списку завдань.
	Синхронізація параметрів і оновлення статусу.
7.	Програмне забезпечення
o	Логіка керування системою забезпечує: 
	Перемикання між режимами (відображення часу та завдань).
	Синхронізацію даних із сервером.
	Управління світлом через кольори та яскравість.

Принцип роботи системи TaskLamp
1.	Ініціалізація системи:
o	ESP32 підключається до WiFi, ініціалізує дисплей, LED кільце та RTC.
o	Завантажується список завдань із сервера.
o	На OLED-дисплеї відображається початкова інформація.
2.	Відображення часу та завдань:
o	Система перемикається між показом часу та списком завдань кожні 5 секунд.
o	Якщо завдання відсутні, виводиться текст "0 tasks found".
3.	Обробка даних потенціометрів:
o	Параметри кольору та яскравості зчитуються з потенціометрів.
o	Користувач може змінювати колір світла залежно від настрою або вимог.
4.	Комунікація із сервером:
o	Дані про завдання отримуються через HTTP-запит.
o	Завдання оновлюються, коли система перемикається в режим відображення списку завдань.
5.	LED індикація:
o	Кольори змінюються залежно від положення потенціометра.
o	Світло адаптується до рівня яскравості, встановленого користувачем.
6.	Реакція на зміни:
o	У разі втрати WiFi-з'єднання або інших проблем із сервером система продовжує відображати останні отримані дані.
o	При повторному з'єднанні завдання оновлюються автоматично.

Ця система об'єднує функціональність розумного світильника з можливістю відображення завдань, що забезпечує зручність і персоналізацію для користувача.
 


Підключення компонентів до ESP32:

 

Опис роботи системи TaskLamp
1.	Ініціалізація системи:
o	Після ввімкнення ESP32 підключається до WiFi-мережі, використовуючи задані параметри (SSID та пароль).
o	Виконується ініціалізація OLED-дисплея, LED кільця та RTC-модуля.
o	На OLED-дисплеї відображається повідомлення про успішний запуск системи.
2.	Відображення інформації:
o	Час: 
	На дисплеї відображається поточний час у форматі ГГ:ХХ:СС, оновлення кожну секунду.
o	Завдання: 
	Список завдань завантажується із сервера через HTTP-запит і відображається на дисплеї.
	Якщо завдань немає, виводиться повідомлення "0 tasks found".
o	Перемикання між режимами (відображення часу та завдань) здійснюється кожні 5 секунд.
3.	Обробка завдань:
o	Завантаження завдань із сервера відбувається під час переходу в режим відображення завдань.
o	Дані завдань обробляються (парсер JSON) і зберігаються у локальному масиві.
4.	Управління LED кільцем:
o	Яскравість: 
	Регулюється через потенціометр (BRIGHTNESS_PIN), значення конвертуються з діапазону 0-4095 у 0-255.
o	Колір: 
	Потенціометр (COLOR_PIN) задає RGB-компоненти: 
	Червоний (R): пропорційно значенню 0-4095.
	Зелений (G): пропорційно до половини значення.
	Синій (B): пропорційно верхній половині значення.
o	Кільце змінює колір та яскравість у режимі реального часу.
5.	Синхронізація із сервером:
o	Дані завдань завантажуються через HTTP-запит (GET).
o	У разі успішного запиту завдання оновлюються. Якщо запит не вдається, виводиться відповідне повідомлення в серійну консоль.
6.	Робота в реальному часі:
o	Постійно оновлюються показники часу, завдань, кольорів і яскравості.
o	Оновлення системи відбувається з затримкою 100 мс для забезпечення плавної роботи.
7.	Реакція на помилки:
o	Якщо WiFi-з'єднання відсутнє, в серійній консолі виводиться повідомлення про проблему.
o	Якщо сервер недоступний або повертає код помилки (не 200), виводиться відповідне повідомлення про проблему.
8.	Простота взаємодії:
o	Система автоматично налаштовує всі компоненти, не потребуючи додаткових дій від користувача після запуску.
o	Користувач може змінювати лише яскравість і колір LED кільця за допомогою потенціометрів.
Ця система поєднує функції відображення часу, списку завдань і керування освітленням у простому та зручному форматі.

Рисунок 2 – Діаграма діяльності IoT- клієнта

1)	Створити програмну реалізацію бізнес логіки та функцій налаштування ІоТ клієнта.
Для створення IoT-клієнта було використано додаток WOKWI. У якості мікроконтролера було обрано ESP32 DevKit V1, який забезпечує керування всіма компонентами та комунікацію із сервером через WiFi. Для відображення даних у реальному часі застосовано OLED-дисплей SSD1306 (128x64), який показує поточний час та список завдань.
Керування освітленням реалізовано за допомогою RGB LED кільця (WS2812B), яке змінює кольори та яскравість залежно від параметрів, заданих потенціометрами. Потенціометр BRIGHTNESS_PIN використовується для регулювання яскравості, а COLOR_PIN для зміни кольору.
Система також інтегрує RTC-модуль (DS1307) для забезпечення точного часу, який відображається на дисплеї. Комунікація із сервером реалізована через HTTP-запити для завантаження списку завдань і синхронізації даних.
Завдання з сервера оновлюються кожні 5 секунд або при переході до режиму їх відображення. У разі перевищення ліміту потужності або іншого аварійного стану система може інтегрувати зумер та світлодіоди для звукових та візуальних сповіщень.
Ця система забезпечує ефективне керування даними, надаючи користувачу інтуїтивно зрозумілий інтерфейс та адаптивну індикацію, що відповідає потребам сучасного IoT-рішення.

#include <WiFi.h>
#include <HTTPClient.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>
#include <Adafruit_NeoPixel.h>
#include <RTClib.h>

// Wi-Fi параметри
const char* ssid = "Wokwi-GUEST"; 
const char* password = ""; 
const char* serverUrl = "http://607f-109-86-145-249.ngrok-free.app/tasks/user/1"; // URL сервера

// Параметри OLED дисплея
#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64
#define OLED_RESET -1
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, OLED_RESET);

// Параметри LED кільця
#define LED_PIN 18 // GPIO18 для WS2812B
#define NUM_LEDS 16
Adafruit_NeoPixel strip = Adafruit_NeoPixel(NUM_LEDS, LED_PIN, NEO_GRB + NEO_KHZ800);

// Об'єкт RTC
RTC_DS1307 rtc;

// Піни потенціометрів
#define BRIGHTNESS_PIN 34 // Пін для яскравості
#define COLOR_PIN 35      // Пін для кольору

// Максимальна яскравість (0-255)
uint8_t brightness = 150;

// Масив для зберігання завдань
#define MAX_TASKS 10
String tasks[MAX_TASKS];
int taskCount = 0;

// Таймер для перемикання між часом і завданнями
unsigned long lastSwitchTime = 0;
const unsigned long switchInterval = 5000; // 5 секунд
bool showTime = true; // Показувати час чи завдання

void setup() {
  // Ініціалізація серійного монітора
  Serial.begin(115200);
  Serial.println("Hello, ESP32!");

  // Ініціалізація Wi-Fi
  WiFi.begin(ssid, password);
  Serial.print("Connecting to Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(1000);
    Serial.print(".");
  }
  Serial.println("\nConnected to Wi-Fi");

  // Ініціалізація OLED дисплея
  if (!display.begin(SSD1306_BLACK, 0x3C)) {
    Serial.println(F("SSD1306 allocation failed"));
    for (;;)
      ;
  }
  display.clearDisplay();
  display.display();

  // Ініціалізація RTC
  if (!rtc.begin()) {
    Serial.println("Couldn't find RTC");
    for (;;)
      ;
  }
  if (!rtc.isrunning()) {
    Serial.println("RTC is NOT running, setting the time!");
    rtc.adjust(DateTime(F(__DATE__), F(__TIME__))); // Встановити час за компіляцією
  }

  // Ініціалізація LED кільця
  strip.begin();
  strip.show(); // Очистити кільце

  // Налаштування піна для потенціометрів
  pinMode(BRIGHTNESS_PIN, INPUT);
  pinMode(COLOR_PIN, INPUT);

  // Завантажити завдання
  loadTasks();
}

void loop() {
  // Оновлення часу
  DateTime now = rtc.now();

  // Кожні 5 секунд перемикатися між часом і завданнями
  if (millis() - lastSwitchTime >= switchInterval) {
    lastSwitchTime = millis();
    showTime = !showTime;

    // Завантажити завдання, якщо переходимо до їх відображення
    if (!showTime) {
      loadTasks(); // Отримати найсвіжіші завдання
    }
  }

  if (showTime) {
    displayTime(now);
  } else {
    displayTasks();
  }

  // Читання значення потенціометрів
  brightness = analogRead(BRIGHTNESS_PIN) / 16; // Перетворення 0-4095 у 0-255
  uint16_t colorValue = analogRead(COLOR_PIN); // Значення кольору 0-4095

  // Визначення кольору залежно від значення
  uint8_t red = map(colorValue, 0, 4095, 0, 255);   // Червоний
  uint8_t green = map(colorValue, 0, 2047, 0, 255); // Зелений
  uint8_t blue = map(colorValue, 2048, 4095, 0, 255); // Синій

  // Застосування яскравості
  strip.setBrightness(brightness);

  // Встановлення кольору
  setRingColor(strip.Color(red, green, blue));

  delay(100); // Оновлення
}

// Функція для управління кольором LED кільця
void setRingColor(uint32_t color) {
  for (int i = 0; i < NUM_LEDS; i++) {
    strip.setPixelColor(i, color);
  }
  strip.show();
}

// Відображення часу на OLED
void displayTime(const DateTime& now) {
  String timeString = String(now.hour()) + ":" + String(now.minute()) + ":" + String(now.second());
  display.clearDisplay();
  display.setTextSize(2);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 0);
  display.println("Time:");
  display.println(timeString);
  display.display();
}

// Відображення завдань на OLED
void displayTasks() {
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0, 0);
  if (taskCount == 0) {
    display.println("0 tasks found");
  } else {
    for (int i = 0; i < taskCount; i++) {
      display.println("- " + tasks[i]);
    }
  }
  display.display();
}

// Завантаження завдань із сервера
void loadTasks() {
  if (WiFi.status() == WL_CONNECTED) {
    HTTPClient http;
    http.begin(serverUrl);
    int httpResponseCode = http.GET();

    if (httpResponseCode == 200) {
      String payload = http.getString();
      parseTasks(payload);
    } else {
      Serial.println("Failed to fetch tasks, HTTP code: " + String(httpResponseCode));
    }
    http.end();
  } else {
    Serial.println("Wi-Fi not connected");
  }
}

// Розбір JSON із сервера
void parseTasks(String payload) {
  // Очищення попередніх завдань
  taskCount = 0;

  // Спрощений парсер JSON
  int startIdx = 0, endIdx = 0;
  while ((startIdx = payload.indexOf("\"title\":\"", endIdx)) >= 0) {
    endIdx = payload.indexOf("\"", startIdx + 9);
    if (endIdx > 0 && taskCount < MAX_TASKS) {
      tasks[taskCount++] = payload.substring(startIdx + 9, endIdx);
    }
  }
}

}

const express = require('express');
const router = express.Router();
const { Task } = require('../models');

// Отримати всі завдання
router.get('/', async (req, res) => {
  try {
    const tasks = await Task.findAll();
    res.json(tasks);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Отримати завдання за ID
router.get('/:id', async (req, res) => {
  try {
    const task = await Task.findByPk(req.params.id);
    if (!task) {
      return res.status(404).json({ message: 'Task not found' });
    }
    res.json(task);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Отримати всі завдання за UserID
router.get('/user/:userId', async (req, res) => {
  try {
    const tasks = await Task.findAll({
      where: {
        userId: req.params.userId,
      },
    });
    if (tasks.length === 0) {
      return res.status(404).json({ message: 'No tasks found for this user' });
    }
    res.json(tasks);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Створити нове завдання
router.post('/', async (req, res) => {
  try {
    const { userId, title, description, dueDate, isCompleted } = req.body;
    const newTask = await Task.create({ userId, title, description, dueDate, isCompleted });
    res.status(201).json(newTask);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Оновити інформацію про завдання
router.put('/:id', async (req, res) => {
  try {
    const task = await Task.findByPk(req.params.id);
    if (!task) {
      return res.status(404).json({ message: 'Task not found' });
    }
    const { title, description, dueDate, isCompleted } = req.body;
    task.title = title || task.title;
    task.description = description || task.description;
    task.dueDate = dueDate || task.dueDate;
    task.isCompleted = isCompleted !== undefined ? isCompleted : task.isCompleted;
    await task.save();
    res.json(task);
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Видалити завдання
router.delete('/:id', async (req, res) => {
  try {
    const task = await Task.findByPk(req.params.id);
    if (!task) {
      return res.status(404).json({ message: 'Task not found' });
    }
    await task.destroy();
    res.json({ message: 'Task deleted successfully' });
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

// Пошук завдань за статусом виконання
router.get('/status/:isCompleted', async (req, res) => {
  try {
    const isCompleted = req.params.isCompleted === 'true';

      where: {
        isCompleted,
